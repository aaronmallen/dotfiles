# Matplotlib

Python library for plots and charts

Sets `MPLCONFIGDIR` to `$XDG_CACHE_HOME/matplotlib` so config and font caches stay out of `~/.matplotlib`.
Loads the setting in Bash and Zsh; the session environment loader also exports it for GUI apps.
